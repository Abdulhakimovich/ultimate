# 📋 Трекер Привычек и Недельный Планер (Habit & Weekly Planner Tracker)

Полнофункциональное веб-приложение для планирования недели, отслеживания привычек и аналитики личной продуктивности.

Дизайн выполнен в **тёплой, минималистичной и естественной палитре** (бежевые, кремовые и кофейные тона с тёмно-коричневыми и синими акцентами) с полным переводом интерфейса на **русский язык**.

---

## 🛠 Стек технологий

- **Фреймворк:** Next.js 15+ (App Router, Server & Client Components)
- **Язык:** TypeScript (строгая типизация)
- **Стилизация:** Tailwind CSS v4 + кастомная CSS-палитра через `@theme`
- **Графики:** Recharts (AreaChart, BarChart) + кастомные анимированные SVG Donut-кольца
- **Управление состоянием:** Zustand + TanStack Query
- **База данных и ORM:** Drizzle ORM + Supabase PostgreSQL с поддержкой Row Level Security (RLS)
- **Авторизация:** Supabase Auth (Email / Пароль + Google OAuth) с локальным офлайн-режимом
- **Анимации:** Framer Motion
- **Формы и валидация:** React Hook Form + Zod
- **Даты:** date-fns (русская локаль `ru`)
- **Иконки:** Lucide React

---

## 📱 Основные разделы приложения

1. **🗓️ Недельный Планер (`/planner`)**
   - Верхняя панель сводки:
     - Заголовок с интерактивным выбором даты начала недели
     - График выполнения задач за неделю (BarChart по дням Пн–Вс)
     - Многосегментное Donut-кольцо общего прогресса недели
     - Быстрый трекер привычек на текущую неделю
   - 7 колонок дней недели (Пн–Вс):
     - Цветовые акценты заголовков (теплый беж для будней, затемнённый для субботы и тёмно-кофейный для воскресенья)
     - Индивидуальные Donut-кольца дневного прогресса
     - Списки задач с возможностью инлайн-редактирования, подсветки выполненных и удаления
     - Пустые строки для быстрого добавления новых задач по клику
     - Счётчики «Завершено» и «Невыполнено»
     - Блоки ежедневной рефлексии: «Заметки», «Что можно сделать лучше?» и «За что я благодарен?» с автосохранением

2. **📅 Месячный Трекер (`/tracker`)**
   - Левая фиксированная панель: интерактивный мини-календарь с навигацией по месяцам, список привычек с цветными бейджами, кнопка добавления привычки
   - Скроллируемая сетка по неделям месяца с интерактивными чекбоксами привычек
   - Инлайн-ввод цели месяца с дебаунсом сохранения
   - Правая панель прогресса по привычкам с редактируемыми месячными целями и расчётом среднего прогресса
   - Модальное окно добавления и редактирования привычки (название, иконка, цвет, цель в днях)

3. **📊 Аналитика (`/analytics`)**
   - Ежедневный столбчатый график выполнения привычек с таблицей процентов и количества выполненных/невыполненных задач
   - Сглаженный график тренда месяца (AreaChart с мягким бежевым градиентом)
   - Навигация между месяцами в реальном времени

4. **🔐 Авторизация (`/login`, `/register`)**
   - Лаконичные формы входа и регистрации с валидацией Zod
   - Поддержка входа через Google OAuth и Email
   - Автоматический переход в гостевой демо-режим, если ключи Supabase не настроены

## 🚀 Запуск проекта

```bash
# Переход в директорию
cd C:\Users\user\.gemini\antigravity\scratch\habit-tracker

# Запуск режима разработки
npm run dev

# Сборка и запуск продакшена
npm run build
npm start
```

После запуска приложение доступно по адресу: **http://localhost:3000**
